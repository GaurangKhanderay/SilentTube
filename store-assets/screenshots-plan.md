# Chrome Web Store Screenshots Plan

We need 4 high-quality screenshots (1280x800 resolution) for the Chrome Web Store submission.

## Screenshot 1: Popup UI
* **Goal**: Show the simple, intuitive toggle interface.
* **Exact browser size**: 1280x800.
* **Exact page**: Any page (ideally a clean, dark background to contrast with the popup). Click the SilentTube extension icon to open the popup.
* **Exact crop**: Center the popup window over the background. Crop to exactly 1280x800.
* **Exact filename**: `store-assets/screenshot-1-popup.png`

## Screenshot 2: YouTube Before
* **Goal**: Show a cluttered YouTube homepage with all distracting elements visible (Shorts, Recommended, Trending).
* **Exact browser size**: 1280x800.
* **Exact page**: `https://www.youtube.com/` (logged in, with personalized recommendations). Ensure the SilentTube extension is disabled or all toggles are OFF.
* **Exact crop**: Full browser window content area (excluding browser UI/tabs if possible, or include them for context if preferred, but keep dimensions 1280x800).
* **Exact filename**: `store-assets/screenshot-2-before.png`

## Screenshot 3: YouTube After
* **Goal**: Show the clean, focused YouTube homepage with SilentTube active.
* **Exact browser size**: 1280x800.
* **Exact page**: `https://www.youtube.com/` (same view as Screenshot 2). Ensure all SilentTube toggles are ON.
* **Exact crop**: Full browser window content area (matching Screenshot 2). The contrast between the cluttered "Before" and the empty "After" is the key selling point.
* **Exact filename**: `store-assets/screenshot-3-after.png`

## Screenshot 4: Settings Showcase (Video Page)
* **Goal**: Demonstrate how SilentTube cleans up the video watching experience (hiding comments, recommended sidebar).
* **Exact browser size**: 1280x800.
* **Exact page**: Any popular YouTube video page (e.g., `https://www.youtube.com/watch?v=...`). Ensure all SilentTube toggles are ON.
* **Exact crop**: Full browser window content area, showing the video player but an empty sidebar and missing comment section.
* **Exact filename**: `store-assets/screenshot-4-video-clean.png`
